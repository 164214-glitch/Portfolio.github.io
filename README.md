
## โครงสร้างไฟล์
```
canva-portfolio/
├── index.html      ← 01 ปกหน้า
├── page-02.html     ← 02 Statement of Purpose
├── page-03.html     ← 03 Profile
├── page-04.html     ← 04 Education
├── page-05.html     ← 05 Activities (Camp/Open House)
├── page-06.html     ← 06 Activities (Camp/Open House)
├── page-07.html     ← 07 Activities (Camp/Open House)
├── page-08.html     ← 08 Activities (วัดความรู้ด้านวิศวกรรมศาสตร์)
├── page-09.html     ← 09 Activities (โครงงานวิจัย)
├── page-10.html     ← 10 Activities (Camp/Open House)
├── page-11.html     ← 11 Activities (ด้านจิตอาสา)
├── page-12.html     ← 12 Thank You
├── style.css       ← ดีไซน์ทั้งหมด (ใช้ร่วมกันทุกหน้า)
├── app.js         ← เมนู, ปุ่มเลื่อนหน้า, กล้องซูมรูป (ใช้ร่วมกันทุกหน้า)
└── images/        ← ไฟล์รูป page-01.jpg ถึง page-12.jpg (แปลงจาก PNG เป็น JPG ให้แล้วเพื่อให้เว็บโหลดเร็ว)
```
## ฟีเจอร์ในเว็บ
- **คลิกที่รูปเพื่อขยายดูเต็มจอ** — มีปุ่ม + / − ซูมเข้าออก, ลากรูปเพื่อเลื่อนดู (ตอนซูม), ดับเบิลคลิก/ดับเบิลแตะเพื่อซูมเร็ว, เลื่อนล้อเมาส์ซูมได้, กด Esc หรือคลิกพื้นหลังเพื่อปิด — ออกแบบมาให้อ่านตัวหนังสือเล็กๆ ในเกียรติบัตรได้ชัดบนมือถือ
- เมนูแบบเต็มจอ (กดไอคอน ☰ มุมขวาบน) แสดงหัวข้อทั้ง 12 หน้า
- ปุ่ม "ก่อนหน้า / ถัดไป" ท้ายทุกหน้า + ปัดซ้าย-ขวาบนมือถือเพื่อเปลี่ยนหน้า + ลูกศร ← → บนคีย์บอร์ด
- รูปค่อยๆ ปรากฏขึ้นตอนโหลดหน้า (fade + scale reveal)
